📖 Como configurar o Google Calendar (passo a passo)
1. Criar projeto no Google Cloud
Acesse console.cloud.google.com → crie um projeto (ex: "meu-tracker").
2. Ativar a Google Calendar API
Menu → APIs e serviços → Biblioteca → procure Google Calendar API → Ativar.
3. Tela de consentimento OAuth
APIs e serviços → Tela de permissão OAuth → tipo Externo → preencha nome do app e seu e-mail → em Usuários de teste, adicione seu próprio Gmail.
4. Criar credenciais
APIs e serviços → Credenciais → Criar credenciais → ID do cliente OAuth → tipo Aplicativo da Web → em Origens JavaScript autorizadas, adicione: 
https://duduhacken-beep.github.io
Clique Criar e copie o Client ID.
5. Colar aqui
Clique em ⚙️ Configurar acima, cole o Client ID, salve, depois clique em 🔗 Conectar e autorize com sua conta Google.
⚠️ Só funciona na versão hospedada
O Google exige um endereço https:// autorizado — a versão local em arquivo (file://) do PC não consegue conectar. Use sempre duduhacken-beep.github.io/Tracker/ para a sincronização com o Google Calendar.

📖 Como configurar o Supabase (passo a passo)
1. Criar conta gratuita
Acesse supabase.com → clique em Start your project → faça login com GitHub.
2. Criar um projeto
Clique em New project → dê um nome (ex: "meu-tracker") → escolha a região mais próxima (South America) → defina uma senha e clique Create new project. Aguarde ~1 min.
3. Criar a tabela
No menu lateral, clique em SQL Editor → clique em New query → cole o código abaixo e clique Run: 
create table tracker_data (
  key text primary key,
  value jsonb,
  updated_at timestamptz default now()
);

alter table tracker_data enable row level security;

create policy "acesso total"
  on tracker_data for all
  using (true)
  with check (true);
4. Copiar suas credenciais
No menu lateral, clique em Project Settings → API. Você vai ver:
• Project URL → copie para o campo URL acima
• anon public (em Project API Keys) → copie para o campo Key acima
5. Conectar
Cole os dois valores nos campos acima e clique em Salvar e conectar. O tracker vai fazer o upload dos seus dados existentes automaticamente. Abra em outro dispositivo e os dados aparecem na hora! 🎉
